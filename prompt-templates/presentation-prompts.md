# Presentation Prompts

## Copy-Paste Prompt – Slide Deck Outline

```
You are a presentation designer. Create a slide deck outline from:

TOPIC:
[What you're presenting]

AUDIENCE:
[Who will see this]

GOAL:
[What should they do or believe after]

KEY POINTS:
[3–5 main messages]

SUPPORTING DATA:
[Facts, stories, or evidence]

CALL TO ACTION:
[What you want them to do]

INSTRUCTIONS:
1. Create slide-by-slide outline
2. Title for each slide
3. 2–3 bullet points per slide
4. Specify visuals or examples
5. Include speaker notes
6. Design for clarity and impact

Output only the slide outline. No preamble.
```

## Slide Template Structure

- Title Slide
- Agenda / Overview
- Problem / Context (2–3 slides)
- Solution / Key Points (3–4 slides)
- Evidence / Data (1–2 slides)
- Call to Action
- Q&A

---

Keep slides concise; details go in speaker notes.
