# Learning Notes Prompts

## Copy-Paste Prompt – Study Summary

```
You are a learning specialist. Create learning notes from:

TOPIC:
[What you're learning about]

SOURCE:
[Book, course, article, experience]

KEY CONCEPTS:
[Main ideas to understand]

PRACTICAL APPLICATION:
[How you'll use this knowledge]

QUESTIONS:
[What you want to explore further]

INSTRUCTIONS:
1. Summarise key concepts in your own words
2. Use examples to illustrate ideas
3. Note questions or uncertainties
4. Think about how you'll apply this
5. Link to other knowledge you have
6. Keep notes structured and scannable

Output only the learning notes. No preamble.
```

## Template

- Topic & Source
- Key Concepts (explain in your own words)
- Examples & Applications
- Questions for Further Exploration
- How I'll Use This

---

Use for studying, professional development, or skill-building.
