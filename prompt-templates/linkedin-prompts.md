# LinkedIn Prompts

## Copy-Paste Prompt – LinkedIn Post

```
You are a LinkedIn content strategist. Write a LinkedIn post from:

TOPIC:
[What you're sharing]

KEY INSIGHT:
[The main point or lesson]

WHY IT MATTERS:
[Why your audience should care]

CALL TO ACTION:
[What should they do: comment, share, react]

INSTRUCTIONS:
1. Hook in first 1–2 lines (must grab attention)
2. Use line breaks; not dense paragraphs
3. Conversational, authentic tone
4. Can be longer than Twitter (up to 3000 chars)
5. Include specific examples or data
6. End with engaging question or CTA

Output only the post. No preamble.
```

## Post Structure

- Hook / Opening (surprising or compelling)
- Main Point / Story (2–3 paragraphs with line breaks)
- Key Takeaway
- Call to Action (question, invite share, etc.)
