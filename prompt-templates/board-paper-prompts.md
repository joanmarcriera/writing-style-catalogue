# Board Paper Prompts

## Purpose

Write comprehensive board-level decision documents.

## Copy-Paste Prompt

```
You are a board papers expert. Write a comprehensive board paper from:

ISSUE:
[Strategic decision or topic]

BACKGROUND:
[Context and why this matters]

OPTIONS:
[2–3 options for board consideration]

ANALYSIS:
[Pros, cons, and financial impact for each option]

BOARD RECOMMENDATION:
[Which option and why]

RISK ASSESSMENT:
[Key risks and mitigation]

IMPLEMENTATION TIMELINE:
[If approved, how and when]

INSTRUCTIONS:
1. Executive summary (1 page)
2. Comprehensive background
3. Objective analysis of options
4. Clear recommendation with rationale
5. Risk and governance implications
6. Timeline and success metrics
7. Length: 8–15 pages

Output only the board paper. No preamble.
```

## Variables to Customise

- `[ISSUE]` → Strategic decision needed
- `[BACKGROUND]` → Why this matters now
- `[OPTIONS]` → Alternatives for consideration
- `[ANALYSIS]` → Financial and operational impact
- `[RECOMMENDATION]` → Which option and why

## Example Output Structure

**Board Paper: Cloud Migration Decision**

**Executive Summary** (1 page)
[Issue, recommendation, approval requested]

**Background** (2 pages)
[Context; timing; prior decisions]

**Option Analysis** (5 pages)
[Each option: pros, cons, cost, timeline, risk]

**Board Recommendation** (1 page)
[Clear recommendation; rationale; success metrics]

**Risk Assessment** (2 pages)
[Key risks; mitigation strategies; contingencies]

**Implementation** (1 page)
[Timeline; resources; governance; next steps]

**Appendices**
[Detailed financials; comparison matrices; supporting analysis]

## Review Checklist

- [ ] Executive summary is 1 page and complete
- [ ] All options presented objectively
- [ ] Financial impact quantified
- [ ] Recommendation is clear and justified
- [ ] Risks are identified with mitigation
- [ ] Implementation timeline is specific
- [ ] Professional formatting throughout
- [ ] Appendices support main narrative
