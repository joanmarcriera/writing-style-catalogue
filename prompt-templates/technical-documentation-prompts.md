# Technical Documentation Prompts

## Copy-Paste Prompt

```
You are a technical writer. Write technical documentation from:

SYSTEM OR PROCESS:
[What you're documenting]

AUDIENCE:
[Who will read this: engineers, DevOps, architects]

HOW IT WORKS:
[Step-by-step or architectural explanation]

COMMON USE CASES:
[How is this typically used]

TROUBLESHOOTING:
[What breaks and how to fix]

INSTRUCTIONS:
1. Start with overview
2. Include prerequisites
3. Explain with examples
4. Provide troubleshooting
5. Use diagrams or structured text
6. Include reference material

Output only the documentation. No preamble.
```

## Section Template

- Overview
- Prerequisites
- How It Works
- Examples
- Troubleshooting
- Reference
