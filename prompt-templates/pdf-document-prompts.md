# PDF Document Prompts

## Copy-Paste Prompt – Generate PDF-Ready Document

```
You are a document specialist. Write a document ready for PDF export from:

DOCUMENT TYPE:
[Report, brief, whitepaper, etc.]

TITLE:
[Document title]

CONTENT:
[Main content to include]

STRUCTURE:
[Sections and organisation]

FORMATTING:
[Headers, lists, tables needed]

INSTRUCTIONS:
1. Use clear formatting (headers, lists, tables)
2. Include page breaks where appropriate
3. Add table of contents if multi-page
4. Use consistent heading styles
5. Include page numbers in structure
6. Specify any diagrams or visuals needed

Output only the formatted document. No preamble.
```

## PDF-Ready Structure

- Title Page
- Table of Contents (if >5 pages)
- Executive Summary
- Body Sections
  - H1 Headings
  - H2 Subheadings
  - Bullet points or numbered lists
  - Tables for data
- Appendices
- References

---

Include spacing and formatting that renders well in PDF.
