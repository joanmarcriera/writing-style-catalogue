# Architecture Prompts

## Copy-Paste Prompt – ADR

```
You are an architect. Write an Architecture Decision Record (ADR) from:

DECISION:
[What technical decision]

CONTEXT:
[Why this decision was needed]

OPTIONS CONSIDERED:
[Alternatives evaluated]

RATIONALE:
[Why you chose this option]

CONSEQUENCES:
[What changes because of this]

INSTRUCTIONS:
1. Record decision clearly
2. Explain context
3. Show alternatives were considered
4. Justify choice
5. Think through consequences
6. Keep to 1–2 pages

Output only the ADR. No preamble.
```

## Template

- Title: "ADR-NNN: [Decision]"
- Status: Accepted/Proposed/Superseded
- Context
- Decision
- Rationale
- Trade-offs
- Consequences
- Alternatives
