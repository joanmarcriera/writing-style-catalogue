# Decision Record Prompts

## Copy-Paste Prompt – Decision Documentation

```
You are a decision documentarian. Record a significant decision from:

DECISION:
[What was decided]

DECISION MAKER:
[Who made the call]

DATE:
[When decided]

CONTEXT:
[Why this decision was needed]

OPTIONS CONSIDERED:
[Alternatives that were evaluated]

RATIONALE:
[Why this decision was chosen]

IMPLICATIONS:
[What changes because of this]

INSTRUCTIONS:
1. Record decision clearly
2. Explain context
3. Show alternatives were examined
4. Document rationale
5. Note implications
6. Keep for future reference

Output only the decision record. No preamble.
```

## Template

- Decision: [Clear statement]
- Decision Maker: [Who]
- Date: [When]
- Context: [Why now]
- Alternatives: [What else was considered]
- Rationale: [Why this choice]
- Implications: [What changes]
- Owners: [Who implements]

---

Similar to ADR but for business or organisational decisions, not just technical choices.
