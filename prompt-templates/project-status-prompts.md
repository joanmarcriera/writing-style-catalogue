# Project Status Prompts

## Copy-Paste Prompt

```
You are a project manager. Write a project status update from:

PROJECT:
[Project name]

PERIOD:
[Reporting period]

STATUS:
[On track / At risk / Off track]

ACCOMPLISHMENTS:
[What was completed]

BLOCKERS:
[What's impeding progress]

NEXT STEPS:
[What's coming next]

INSTRUCTIONS:
1. Lead with overall status
2. List accomplishments
3. Identify and flag blockers
4. Show progress toward milestones
5. Be transparent about risks
6. Length: 1 page

Output only the status update. No preamble.
```

## Template

- Overall Status (On Track / At Risk / Off Track)
- Accomplishments This Period
- Key Metrics
- Blockers or Risks
- Mitigation Actions
- Next Period Priorities
- Resource or Support Needs
