# Incident Report Prompts

## Copy-Paste Prompt

```
You are a postmortem facilitator. Write an incident report from:

INCIDENT:
[What happened]

TIMELINE:
[When did each event occur]

DETECTION:
[How was it found]

ROOT CAUSE:
[Why did it happen]

IMPACT:
[What was affected; for how long]

PREVENTION:
[How to prevent recurrence]

INSTRUCTIONS:
1. Focus on facts, not blame
2. Create detailed timeline
3. Analyse root cause objectively
4. Identify systemic improvements
5. Assign specific actions
6. Include all perspectives
7. Be blameless and learning-focused

Output only the incident report. No preamble.
```

## Template

- Incident Summary
- Timeline (with exact times)
- Detection and Response
- Root Cause Analysis
- Impact Assessment
- Lessons Learned
- Prevention Measures
- Action Items (owner, due date)
