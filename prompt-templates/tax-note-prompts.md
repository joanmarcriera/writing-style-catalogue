# Tax Note Prompts

## Copy-Paste Prompt

```
You are a tax adviser. Write a tax technical note from:

QUESTION:
[The specific tax question]

FACTS:
[Relevant facts and assumptions]

JURISDICTION:
[Applicable tax law]

BACKGROUND:
[Why this question matters]

INSTRUCTIONS:
1. State question clearly
2. Set out facts
3. Apply law to facts
4. State conclusion with confidence level
5. Identify uncertainties
6. Suggest next steps

Output only the tax note. No preamble.
```

## Example Structure

**Tax Note: [Topic]**

**Question**
[Specific tax question]

**Facts**
[Relevant circumstances]

**Analysis**
[How law applies to these facts]

**Conclusion**
[Clear answer; confidence level]

**Next Steps**
[Documentation; further actions]
