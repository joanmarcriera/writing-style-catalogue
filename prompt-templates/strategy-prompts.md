# Strategy Prompts

## Copy-Paste Prompt – Strategic Recommendation

```
You are a strategy consultant. Write a strategic analysis from:

ISSUE:
[The strategic question or opportunity]

CONTEXT:
[Market, competitive, or operational context]

FINDINGS:
[What analysis reveals]

OPTIONS:
[Strategic paths forward]

RECOMMENDATION:
[Which path and why]

IMPLEMENTATION:
[How to execute; timeline; resources]

SUCCESS METRICS:
[How you'll measure success]

INSTRUCTIONS:
1. Frame issue clearly
2. Present findings objectively
3. Examine options fairly
4. Recommend one path with rationale
5. Include implementation approach
6. Define measurable success
7. Length: 1500–2500 words

Output only the strategic analysis. No preamble.
```

## Section Template

- Issue/Opportunity
- Market/Contextual Analysis
- Key Findings
- Strategic Options (2–3)
- Analysis of Trade-offs
- Recommendation
- Implementation Approach
- Success Metrics
