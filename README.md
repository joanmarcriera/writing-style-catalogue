# Writing Style Catalogue

A practical, reusable catalogue of writing styles, prompt templates, document-generation skills, and examples for use with Large Language Models.

## What is this?

A curated collection of writing frameworks, prompt templates, and workflows to help you generate professional, high-quality documents quickly using AI. This catalogue includes:

- **Styles**: Named writing frameworks (Smart Brevity, BLUF, Minto, etc.)
- **Prompt Templates**: Copy-paste prompts for common document types
- **Skills**: Processes for creating complex multi-part documents
- **Workflows**: End-to-end examples combining styles, skills, and templates
- **Examples**: Real-world samples showing each style in action
- **Checklists**: Quality reviews and selection guides

## Quick Start

1. **Choose a Style**: See [STYLE-SELECTION-GUIDE.md](STYLE-SELECTION-GUIDE.md)
2. **Pick a Prompt Template**: See [prompt-templates/](prompt-templates/)
3. **Copy the Template**: Paste it into your LLM
4. **Customise Variables**: Replace placeholders with your content
5. **Review Against Checklist**: Use checklists/ to validate output
