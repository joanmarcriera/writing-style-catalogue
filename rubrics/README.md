# Rubrics

Rubrics are stricter than checklists. Use them when an output matters enough to score before it is sent, published, or converted into a formal artefact.

## Available rubrics

| Rubric | Use for |
|---|---|
| [Executive Communication Rubric](executive-communication-rubric.md) | CIO/CFO updates, executive memos, approval requests |
| [Board Paper Rubric](board-paper-rubric.md) | Board papers, governance papers, committee submissions |
| [Tax Note Rubric](tax-note-rubric.md) | Tax technical notes and adviser memos |
| [Technical Documentation Rubric](technical-documentation-rubric.md) | Runbooks, ADRs, architecture docs, SOPs |
| [LLM Output Quality Rubric](llm-output-quality-rubric.md) | Any generated draft before human editing |
| [Slide Deck Rubric](slide-deck-rubric.md) | Executive, board, client, or internal presentation outlines |
| [Website Marketing and SEO Rubric](website-marketing-seo-rubric.md) | Website audits, SEO reports, content plans, conversion reviews |

## Scoring

Use a 1-5 score for each criterion:

- **1**: Unusable without major rework
- **2**: Partly useful but contains material gaps
- **3**: Adequate first draft
- **4**: Professionally usable after light review
- **5**: Strong, publication-ready, and audience-fit

Anything containing a factual error, invented citation, unsupported legal/tax conclusion, or unclear decision ask cannot score above **3**, regardless of writing quality.
