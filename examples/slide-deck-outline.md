# Slide Deck Outline Example

**Presentation: Cloud Migration Business Case – 30-minute presentation**

---

**Slide 1: Title Slide**
- Title: "Modernising Our Infrastructure: Cloud Migration Strategy"
- Subtitle: "Investment decision required by end June"
- Speaker name and date

**Slide 2: Agenda**
- Current state and challenges
- Cloud solution overview
- Financial case
- Implementation plan
- Decision required

**Slide 3: Current Challenge**
- Headline: "Ageing Infrastructure Limits Our Growth"
- Key point: Data centre lease expires in 36 months
- Renewal cost: £3.6M over 5 years
- Cannot scale efficiently beyond current capacity

**Slide 4: Market Context**
- Competitors already cloud-native
- Cloud provides competitive advantage in speed
- Customer expectations for modern, reliable infrastructure

**Slide 5: Cloud Solution Overview**
- Migrate to AWS (managed platform)
- Phased approach (low risk)
- Timeline: 18 months
- Result: 99.9% uptime (vs. current 98.5%)

**Slide 6: Financial Case**
- Chart: 5-year cost comparison (on-prem renewal vs. AWS)
- Annual savings: £1.5M
- Payback: 18 months
- ROI: 85% by Year 5

**Slide 7: Key Risks & Mitigation**
- Risk 1: Migration complexity → External partner support
- Risk 2: Operational learning curve → Dedicated team + training
- Risk 3: Cost overrun → Fixed-price vendor contract

**Slide 8: Implementation Timeline**
- Gantt chart: Planning (Q2), Phase 1 (Q3), Phase 2 (Q4), Completion (Q1 2027)
- Key milestones and dependencies

**Slide 9: The Ask**
- Board approval to proceed
- £600k budget for Phase 1
- Decision required: Today

**Slide 10: Q&A**
- Open discussion

---

**Presentation Notes:**
- Total 30 minutes: 20 min presentation + 10 min Q&A
- Bring detailed financial model as backup
- Emphasis on low risk via phased approach
- Highlight strategic advantage (speed to market)

**Key principles shown:**
- Clear narrative arc
- Each slide has one idea
- Progression: Problem → Solution → Cost → Ask
- Data supports claims
- Call to action is clear
