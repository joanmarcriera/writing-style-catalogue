# Problem / Impact / Recommendation / Next Steps

Use this pattern when the reader needs to understand an issue, its consequences, and the proposed response.

## Structure

```text
Problem: [What is wrong, missing, delayed, exposed, or at risk]
Impact: [Financial, operational, customer, regulatory, or strategic effect]
Recommendation: [What should be done and why this option is preferred]
Next steps: [Actions, owners, dates, decision required]
```

## Good for

- IT leadership updates
- Supplier escalations
- Change proposals
- Risk remediations
- Short executive memos

## Prompt line

```text
Structure the output as Problem / Impact / Recommendation / Next Steps. Quantify the impact where possible and make the next steps owner-led.
```

## Quality check

- The problem is specific.
- Impact is not exaggerated.
- Recommendation is actionable.
- Next steps are sequenced and dated.
