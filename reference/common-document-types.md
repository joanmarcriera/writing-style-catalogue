# Common Document Types & Recommended Styles

Quick reference for what style to use for different documents.

| Document Type | Recommended Style | Length | Audience |
|---------------|-------------------|--------|----------|
| Email | BLUF | < 1 page | Direct recipient |
| Quick Update | Smart Brevity | 1–2 pages | Executives/leadership |
| Memo | Minto or BLUF | 1–2 pages | Team/decision-maker |
| Recommendation | Minto Pyramid | 2–5 pages | Leadership |
| Board Paper | Board Paper | 10–20 pages | Board |
| Executive Brief | Executive Briefing | 2–3 pages | C-Suite |
| Technical Doc | Technical Documentation | 5–50 pages | Engineers |
| Project Status | Smart Brevity | 1–2 pages | Stakeholders |
| Instructions/How-To | Tutorial or Plain English | 5–20 pages | Users |
| Tax Analysis | Tax Advisory | 2–5 pages | Client/adviser |
| Legal Document | Legal Professional | Variable | Legal context |
| Incident Report | Incident Report | 3–8 pages | Team/leadership |
| Architecture Decision | ADR | 1–2 pages | Engineers |
| Job Application | Job Application | 1 page | Recruiter |
| LinkedIn Post | Social Media | 1–3 sentences | Network |
| Sales Email | Persuasive Sales | < 150 words | Prospect |
| Meeting Notes | Meeting Notes | 1–2 pages | Attendees |
| FAQ | FAQ | Variable | Users |

## Style by Urgency

**Need a decision in the next hour**
→ BLUF or Smart Brevity

**Need a decision this week**
→ Minto Pyramid or Executive Briefing

**Need a comprehensive decision**
→ Board Paper or Consulting Style

**Need to document for future reference**
→ Technical Documentation or ADR
