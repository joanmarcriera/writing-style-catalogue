# Good vs. Bad Prompts: Examples

Learn by example. See what makes a prompt effective.

## Example 1: Email Writing

**Bad Prompt**
```
Write an email
```
Result: Generic, unclear, unusable.

**Good Prompt**
```
Write a professional email to our CFO requesting approval for a £600k cloud migration investment. 
- Lead with the bottom line (we should approve it)
- Include: annual savings (£1.5M), payback (18 months), timeline (start Q3)
- Keep under 300 words
- Tone: professional but conversational
- Ask for a decision by end of week
```
Result: Specific, actionable, ready to send.

## Example 2: Strategic Analysis

**Bad Prompt**
```
Analyse this market opportunity
```
Result: Vague analysis, uncertain conclusions.

**Good Prompt**
```
Analyse the SaaS market opportunity in manufacturing:
- Market size: £2B globally, growing 15% annually
- Our capabilities: inventory management, supply chain optimisation
- Competitive landscape: 3 major players, 20+ smaller competitors
- Customer acquisition strategy: ? (what we're trying to figure out)

Provide:
1. Market fit assessment (strong/moderate/weak)
2. Top 3 customer acquisition approaches
3. Risks and mitigation
4. Revenue forecast (18-month horizon)
```
Result: Structured analysis addressing specific questions.

## Example 3: Documentation

**Bad Prompt**
```
Document this process
```
Result: Incomplete, unclear instructions.

**Good Prompt**
```
Create step-by-step documentation for our customer onboarding process:
- Assume reader is a new employee with no prior knowledge
- Include decision points (e.g., "if customer has existing system...")
- Add screenshots/diagram specifications where complex
- Troubleshooting section for 3 common problems
- Use simple language; no jargon
- Target length: 3-5 pages
```
Result: Complete, user-friendly documentation.

## Key Differences

| Bad Prompt | Good Prompt |
|-----------|------------|
| Vague | Specific details |
| No context | Clear context |
| Unclear output | Defined format |
| No constraints | Constraints set |
| One sentence | Multiple sentences |
| Generic | Customised to you |
