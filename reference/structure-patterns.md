# Common Structural Patterns

Reusable structures for common writing tasks.

## Problem → Solution → Action

Used for: Recommendations, proposals, problem-solving memos

```
[State the Problem]
[Show Why It Matters]
↓
[Propose the Solution]
[Explain Why It's the Right Choice]
↓
[What We Need to Do]
[Timeline & Resources]
```

## Situation → Complication → Resolution

Used for: Updates, announcements, storytelling

```
[Context: What's the situation]
[Complication: What's the challenge]
[Resolution: How we're addressing it]
[Next Steps: What comes next]
```

## Question → Analysis → Conclusion

Used for: Tax notes, technical decisions, analytical memos

```
[Clear Question]
[Relevant Facts]
[Analysis of the Question]
[Conclusion]
[Next Steps]
```

## Before → After → Results

Used for: Case studies, transformation stories, impact communication

```
[Initial Situation]
[What Changed / What We Did]
[Measurable Results]
[Lessons or Implications]
```

## Option A vs. Option B vs. Option C

Used for: Decision documents, comparisons, strategic choices

```
[Option A: Pros / Cons / Impact]
[Option B: Pros / Cons / Impact]
[Option C: Pros / Cons / Impact]
↓
[Recommendation & Rationale]
```

---

Match your structure to your message type. The right structure makes your message clearer.
