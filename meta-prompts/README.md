# Meta Prompts

Use these prompts when the first prompt or first output is not good enough.

## Available meta-prompts

| Meta-prompt | Use when |
|---|---|
| [Improve This Prompt](improve-this-prompt.md) | Your prompt is vague or produces weak output |
| [Critique This Output](critique-this-output.md) | You want a rigorous review before editing |
| [Convert Notes to Artefact](convert-notes-to-artefact.md) | You have messy notes and need a finished document type |
| [Create Template from Example](create-template-from-example.md) | You have a good example and want a reusable prompt/template |
| [Build Style Guide from Samples](build-style-guide-from-samples.md) | You have samples and want to extract a house style |
| [Compress Without Losing Meaning](compress-without-losing-meaning.md) | You need a shorter version without losing substance |

## Use order

1. Use [Improve This Prompt](improve-this-prompt.md) before generating.
2. Use the improved prompt to create a draft.
3. Use [Critique This Output](critique-this-output.md) against the draft.
4. Use the relevant [rubric](../rubrics/) before final use.
