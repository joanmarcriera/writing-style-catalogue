# Skill: Create FAQ

## What This Skill Does

Compiles frequently asked questions with clear, helpful answers to support users or customers.

## When to Use It

- Customer support resources
- Product documentation
- Customer onboarding
- Internal knowledge base

## Copy-Paste Prompt

```
You are a FAQ specialist. Create an FAQ for:

TOPIC:
[What questions people ask about]

AUDIENCE:
[Who will use this FAQ]

COMMON QUESTIONS:
[Questions you know people ask]

CONTEXT:
[Background that helps answer questions]

INSTRUCTIONS:
1. Organise by topic or flow
2. Answer clearly and concisely
3. Link related questions
4. Use simple language
5. Include contact for unanswered questions

Output as Q&A pairs, grouped by topic.
```

## Structure

- Introduction (how to use this FAQ)
- Topic 1
  - Q: [Question]
  - A: [Clear answer with examples if needed]
- Topic 2
  - Q: [Question]
  - A: [Clear answer]
- Contact/Escalation (if question not answered)

---

FAQs work best when updated based on actual customer questions.
