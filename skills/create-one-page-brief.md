# Skill: Create One-Page Brief

## What This Skill Does

Distils complex information into a single compelling page for busy decision-makers.

## When to Use It

- Executive briefings
- Quick decision documents
- Proposal cover pages
- Investment pitch summaries
- Strategic overviews

## Inputs Required

- Key information to convey
- Desired output style (Smart Brevity, BLUF, etc.)
- Audience level and urgency
- Any critical decisions or asks

## Copy-Paste Prompt

```
You are a briefing specialist. Create a one-page brief from:

TOPIC:
[What you're briefing on]

CONTEXT:
[Why this matters]

KEY POINTS:
[3–5 essential facts]

RECOMMENDATION OR ASK:
[What decision or action needed]

CONSTRAINTS:
[Must fit exactly one page]

INSTRUCTIONS:
1. Lead with headline
2. Use bullet points, not paragraphs
3. Quantify impact with numbers
4. Include one visual or simple diagram if possible
5. End with clear ask
6. Target: fit on one page when printed

Output only the one-page brief. No preamble.
```

## Suggested Output Structure

- Headline (one compelling line)
- 3–5 Key Points (bulleted)
- Impact/Metrics
- Recommendation or Ask
- Next Steps

## Quality Controls

- [ ] Fits one printed page
- [ ] Headline is clear and compelling
- [ ] Each bullet is one sentence maximum
- [ ] Numbers and data included
- [ ] Ask is specific and clear
- [ ] Scannable in under 1 minute
- [ ] Professional formatting

## Common Failure Modes

- Too much text for one page (cut to essentials)
- Unclear headline (make it specific, not generic)
- Missing ask (always include what you need)
- Buried key points (lead with most important)

## Example Request

"Create a one-page brief for the CFO on cloud migration: savings of £1.5M annually, 18-month implementation, £600k upfront cost. Include ROI metrics and capital approval request."

---

Use concise language. Omit nice-to-knows; include only must-knows.
