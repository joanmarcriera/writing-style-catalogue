# Skill: Create Comparison Table

## What This Skill Does

Organises information in a structured table format for easy comparison of options or features.

## When to Use It

- Comparing pricing or product options
- Feature comparison (products, tools, vendors)
- Trade-off analysis
- Decision support materials

## Copy-Paste Prompt

```
You are a comparison specialist. Create a comparison table for:

ITEMS TO COMPARE:
[Products, options, or approaches]

COMPARISON CRITERIA:
[What dimensions to compare on]

DATA:
[Specific data for each item]

INSTRUCTIONS:
1. Clear headers and rows
2. Consistent data format
3. Highlight key differences
4. Include pros/cons if helpful
5. Use consistent units
6. Make decision-friendly

Output as markdown table or structured format.
```

---

Keep tables concise; more than 6 columns becomes hard to scan.
