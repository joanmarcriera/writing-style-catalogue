# Skill: Create Runbook

## What This Skill Does

Documents procedures for responding to specific situations or incidents (operational runbooks).

## When to Use It

- Incident response procedures
- Operational troubleshooting
- Emergency protocols
- On-call or escalation procedures

## Copy-Paste Prompt

```
You are a runbook specialist. Write an operational runbook for:

SITUATION:
[What situation the runbook covers]

TRIGGER:
[What indicates you need to follow this]

RESPONSE STEPS:
[What to do and in what order]

ESCALATION PATH:
[Who to contact if needed]

VERIFICATION:
[How to know if you've fixed it]

INSTRUCTIONS:
1. Assume user might be in crisis
2. Number steps clearly
3. Include decision points
4. Show escalation triggers
5. Provide verification/resolution check

Output only the runbook. No preamble.
```

## Structure

- Situation/Incident Type
- Detection & Trigger
- Initial Response Steps
- Escalation Path & Thresholds
- Verification of Resolution
- Post-Incident Actions (if applicable)

---

Runbooks for critical incidents should be reviewed and updated quarterly.
