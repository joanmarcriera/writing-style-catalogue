# Skill: Create SOP (Standard Operating Procedure)

## What This Skill Does

Documents a standard process so anyone can follow it consistently without deviation.

## When to Use It

- Documenting critical processes
- Onboarding new team members
- Ensuring consistency across teams
- Knowledge preservation

## Copy-Paste Prompt

```
You are a process documentation specialist. Write an SOP for:

PROCESS:
[What process to document]

AUDIENCE:
[Who will follow this: new hires, team members, etc.]

CURRENT PRACTICE:
[How it's currently done]

SUCCESS CRITERIA:
[What "done right" looks like]

INSTRUCTIONS:
1. Step-by-step (numbered)
2. Clear, simple language
3. Include templates if needed
4. Show expected outcomes
5. Flag any approvals or checkpoints
6. Include troubleshooting

Output only the SOP. No preamble.
```

## Structure

- Title & Purpose
- Prerequisites
- Step-by-Step Instructions
- Verification/Quality Check
- Common Issues & Fixes
- Approval or Sign-Off (if needed)

---

Review and update SOPs annually or after significant process changes.
