# Skill: Create Email Sequence

## What This Skill Does

Develops a series of coordinated emails for outreach, nurturing, or communication campaigns.

## When to Use It

- Sales outreach sequences (3–5 emails over time)
- Onboarding communication flows
- Product announcements
- Customer education series

## Inputs Required

- Campaign goal and audience
- Key messages per email
- Timing/frequency of sequence
- Call-to-action for each email

## Copy-Paste Prompt

```
You are an email sequence specialist. Create an email sequence from:

GOAL:
[What the sequence should accomplish]

AUDIENCE:
[Who you're contacting]

SEQUENCE LENGTH:
[How many emails; timing between them]

KEY MESSAGES:
[What each email should convey]

INSTRUCTIONS:
1. Each email builds on the previous
2. Vary subject lines and angles
3. Include clear CTA in each
4. Space out over appropriate timeline
5. Show email copy for each
6. Include send timing recommendations

Output only the email sequence. No preamble.
```

## Template (Sales Example)

- Email 1: Introduction + Value Prop (Day 1)
- Email 2: Social Proof + Case Study (Day 3)
- Email 3: Urgency + Special Offer (Day 7)
- Email 4: Last Chance + CTA (Day 14)

---

Test sequences for response rates; optimise based on open/click data.
