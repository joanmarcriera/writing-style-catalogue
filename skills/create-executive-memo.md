# Skill: Create Executive Memo

## What This Skill Does

Writes a formal memo for executive review on strategic or operational matters.

## When to Use It

- Proposing policy changes
- Briefing executives on market or operational issues
- Requesting budget or resource approvals
- Communicating strategic decisions

## Inputs Required

- Topic and purpose
- Key facts and recommendations
- Decision or action required
- Timeline and stakeholder impact

## Copy-Paste Prompt

```
You are an executive memo specialist. Write an executive memo from:

TO:
[Executive recipient(s)]

SUBJECT:
[Clear subject line]

PURPOSE:
[Why you're writing]

RECOMMENDATION:
[What you recommend]

KEY FACTS:
[Supporting information]

ACTION REQUIRED:
[What you need from them]

INSTRUCTIONS:
1. Keep under 2 pages
2. Lead with recommendation
3. Support with facts
4. Be clear about what you're asking
5. Professional tone
6. Include timeline

Output only the memo. No preamble.
```

## Structure

- TO/FROM/DATE/SUBJECT
- Purpose (1 sentence)
- Recommendation (headline)
- Supporting Facts (2–3 bullets)
- Action Required & Timeline
- Contact/Discussion
