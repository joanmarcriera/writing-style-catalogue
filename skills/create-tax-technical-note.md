# Skill: Create Tax Technical Note

## What This Skill Does

Produces a professional tax analysis answering specific tax questions with supporting analysis and conclusions.

## When to Use It

- Tax compliance questions
- Structuring advice
- Transaction tax analysis
- Professional client communications

## Copy-Paste Prompt

```
You are a tax adviser. Write a tax technical note for:

QUESTION:
[The specific tax question]

FACTS:
[Relevant circumstances]

JURISDICTION:
[Tax law applicable]

CONTEXT:
[Why this matters]

Instructions: See [prompt-templates/tax-note-prompts.md](../prompt-templates/tax-note-prompts.md)
```

---

Always have a qualified tax adviser review before client delivery.
