# Skill: Create Prompt Library

## What This Skill Does

Curates a collection of reusable LLM prompts for specific tasks or domains.

## When to Use It

- Building company-specific prompt templates
- Creating team resources
- Documenting best practices
- Training others on prompt engineering

## Copy-Paste Prompt

```
You are a prompt engineer. Create a prompt library for:

DOMAIN:
[What domain or task area]

USE CASES:
[Specific tasks the library covers]

EXPERTISE:
[Context or knowledge the prompts should include]

INSTRUCTIONS:
1. Organise prompts by use case
2. Include example prompts
3. Show variables to customise
4. Include expected output examples
5. Add usage tips and common mistakes
6. Make prompts copy-paste ready

Output prompt library with examples.
```

## Structure

- Library Purpose
- Use Case 1: [Prompt with variables and examples]
- Use Case 2: [Prompt with variables and examples]
- Tips for Using This Library
- Common Mistakes to Avoid
