# Skill: Create Checklist

## What This Skill Does

Builds a practical, actionable checklist for processes, quality assurance, or project tasks.

## When to Use It

- Quality review before publishing
- Process standardisation
- Onboarding or training
- Project or event planning

## Copy-Paste Prompt

```
You are a checklist designer. Create a checklist for:

PROCESS OR TASK:
[What the checklist covers]

CONTEXT:
[Who will use it; when]

STEPS OR ITEMS:
[Key tasks or checkpoints]

INSTRUCTIONS:
1. Start with most critical items
2. Use clear, actionable language
3. Group related items
4. Make it quick to use (not exhaustive)
5. Include verification steps

Output only the checklist. No preamble.
```

## Structure

- Title
- Purpose (1 sentence)
- Grouped Items (with [ ] checkboxes)
- Sign-off or verification

---

Practical checklists are more useful than exhaustive ones.
