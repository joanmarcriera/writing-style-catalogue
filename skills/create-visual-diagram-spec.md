# Skill: Create Visual Diagram Spec

## What This Skill Does

Specifies a visual diagram or infographic for a designer to create.

## When to Use It

- Architecture diagrams
- Process flows
- Customer journey maps
- Data visualisations
- Organisational structures

## Copy-Paste Prompt

```
You are a visual design brief specialist. Create a diagram specification for:

PURPOSE:
[What this diagram communicates]

CONTENT:
[What elements to show]

AUDIENCE:
[Who will use this]

STYLE:
[How it should look]

INSTRUCTIONS:
1. Describe diagram type (flowchart, system architecture, etc.)
2. List key elements and relationships
3. Specify visual style and colours if needed
4. Show information hierarchy
5. Include labels and legend
6. Provide usage context

Output detailed visual specification for designer.
```

---

Good visual specs make it clear what designers should create.
