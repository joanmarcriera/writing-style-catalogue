# Skill: Create Playbook

## What This Skill Does

Documents repeatable best practices or responses for specific scenarios (e.g., sales playbook, marketing playbook).

## When to Use It

- Sales processes and messaging
- Marketing campaigns
- Customer success processes
- Crisis response

## Copy-Paste Prompt

```
You are a playbook specialist. Create a playbook for:

SCENARIO:
[What situation the playbook covers]

CONTEXT:
[When and why you'd use this playbook]

PLAYS:
[Specific steps, tactics, or messaging]

SUCCESS CRITERIA:
[How you measure if the playbook worked]

INSTRUCTIONS:
1. Provide specific, actionable plays
2. Include templates if helpful
3. Show decision points
4. Include success metrics
5. Keep it modular (plays can be mixed)

Output as list of plays with context.
```

## Structure

- Playbook Purpose
- Trigger/When to Use
- Play 1 (specific action or approach)
- Play 2 (specific action or approach)
- Success Metrics
- Variations or Adjustments

---

Sales playbooks might include pitch messaging, objection handling, discovery questions.
