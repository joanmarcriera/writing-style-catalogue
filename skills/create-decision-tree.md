# Skill: Create Decision Tree

## What This Skill Does

Visualises a decision process with branches showing different paths based on criteria or choices.

## When to Use It

- Customer support workflows
- Troubleshooting guides
- Process navigation
- Strategic decision frameworks

## Copy-Paste Prompt

```
You are a decision tree designer. Create a decision tree for:

PROCESS/SCENARIO:
[What decision path you're mapping]

DECISION POINTS:
[Key questions or criteria]

OUTCOMES:
[Possible endpoints or decisions]

INSTRUCTIONS:
1. Start with primary decision
2. Show each branch clearly
3. Label decision criteria
4. Show outcomes at endpoints
5. Use clear, simple language
6. Make it navigable

Output decision tree in text format or ASCII diagram.
```

Use for customer support, troubleshooting, or process navigation.
