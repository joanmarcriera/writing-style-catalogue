# Skill: Create Roadmap

## What This Skill Does

Develops a timeline-based roadmap showing priorities, dependencies, and delivery phases.

## When to Use It

- Product roadmaps
- Project planning
- Technology roadmaps
- Strategic initiatives planning

## Copy-Paste Prompt

```
You are a roadmap specialist. Create a roadmap for:

INITIATIVE:
[What you're planning for]

TIME HORIZON:
[6 months, 12 months, 3 years]

PRIORITIES:
[Key initiatives to include]

DEPENDENCIES:
[What depends on what]

INSTRUCTIONS:
1. Organise by time period (quarters or phases)
2. Show dependencies
3. Indicate priority levels
4. Include key milestones
5. Make it scannable
6. Show confidence levels if appropriate

Output as timeline or phased roadmap.
```

---

Product roadmaps typically show 6–12 months; strategic roadmaps may go 3+ years.
