# Skill: Create Training Material

## What This Skill Does

Develops structured, learner-friendly training content with clear objectives, examples, and assessments.

## When to Use It

- Employee onboarding materials
- Skill development programs
- Customer education
- Team process training

## Copy-Paste Prompt

```
You are a training specialist. Create training material for:

TOPIC:
[What to train people on]

AUDIENCE:
[Who will take the training]

LEARNING OBJECTIVES:
[What they should be able to do after]

CONTENT:
[Key concepts and examples]

INSTRUCTIONS:
1. Start with clear learning objectives
2. Break content into digestible modules
3. Include worked examples
4. Add practice exercises
5. Include assessment or quiz
6. Keep engaging and clear

Output only the training material. No preamble.
```

## Structure

- Learning Objectives
- Module 1: [Topic] (explanation, example, exercise)
- Module 2: [Topic] (explanation, example, exercise)
- Practice Exercise (apply learning)
- Assessment/Quiz
- References or Further Learning

---

Include real-world examples and opportunities to practice.
