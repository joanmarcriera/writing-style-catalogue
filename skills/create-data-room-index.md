# Skill: Create Data Room Index

## What This Skill Does

Organises and indexes documents in a data room for transaction, audit, or regulatory purposes.

## When to Use It

- M&A due diligence
- Regulatory compliance
- Audit preparation
- Investor due diligence

## Copy-Paste Prompt

```
You are a data room specialist. Create an index for:

PURPOSE:
[M&A, audit, regulatory, etc.]

DOCUMENTS:
[What documents need to be organised]

CATEGORIES:
[How to organise them]

INSTRUCTIONS:
1. Create logical folder structure
2. Index each document with metadata
3. Show version control
4. Include access restrictions if needed
5. Provide search functionality
6. Create access protocol

Output data room index/folder structure.
```

---

Data room organisation is critical for smooth transactions and compliance reviews.
