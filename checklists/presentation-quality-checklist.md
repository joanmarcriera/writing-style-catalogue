# Checklist: Presentation Quality Review

Before finalising a presentation.

## Content

- [ ] Clear narrative arc (problem → solution → action)
- [ ] Each slide has one main idea
- [ ] Key data/evidence supports claims
- [ ] Logical flow from slide to slide
- [ ] Call to action is clear
- [ ] Conclusion restates key message
- [ ] Final main slide states the decision, commitment, or action required
- [ ] Risks or objections are addressed before the ask

## Slides

- [ ] Max 2–3 bullets per slide
- [ ] Bullet text is short (not paragraphs)
- [ ] Visuals enhance message (not decorative)
- [ ] Charts and graphs are clear and labelled
- [ ] No more text than needed
- [ ] Consistent font sizes and styles
- [ ] Readable on a large screen
- [ ] Every visual has a stated purpose

## Speaker Materials

- [ ] Speaker notes are complete for each slide
- [ ] Notes include timing cues
- [ ] Backup data is prepared (if questions arise)
- [ ] Transition between slides is smooth
- [ ] Q&A section has prepared answers
- [ ] Presenter can explain all numbers and assumptions

## Professional Standards

- [ ] Spelling and grammar correct
- [ ] Consistent colour scheme
- [ ] Professional (not cartoonish) appearance
- [ ] Slide numbers visible
- [ ] Date and presenter name on title slide

## Delivery Readiness

- [ ] Practised delivery (timing is correct)
- [ ] Confident with all content
- [ ] Can answer likely questions
- [ ] Technology tested (projector, remote, etc.)

---

A good presentation tells a story, not just displays slides.
