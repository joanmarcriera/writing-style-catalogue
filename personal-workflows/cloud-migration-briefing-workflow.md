# Workflow: Cloud Migration Briefing

Complete process for presenting cloud infrastructure change to stakeholders.

## Phase 1: Analysis (1–2 weeks)

**Step 1: Assess Current State**
- Current infrastructure costs (capex + opex)
- Performance metrics
- Operational burden
- Scaling constraints

**Step 2: Define Cloud Solution**
- Provider selection (AWS, Azure, GCP, etc.)
- Architecture design
- Migration approach (phased, cutover, etc.)
- Timeline and phases

**Step 3: Financial Analysis**
- Cloud migration costs (one-time)
- Ongoing cloud costs
- Savings vs. renewal
- Payback period and ROI
- Multi-year financial projection

**Step 4: Risk Assessment**
- Technical risks (integration, data migration)
- Operational risks (team capability)
- Business risks (service continuity)
- Mitigation strategies

## Phase 2: Briefing Creation (1–2 weeks)

**For Board/Exec Briefing**:
- Use [Executive Briefing Style](../styles/executive-briefing.md)
- Use [Board Paper Prompt](../prompt-templates/board-paper-prompts.md)
- Length: 8–12 pages
- Include: background, options, recommendation, risks, implementation

**For Technical Team**:
- Use [Technical Documentation](../styles/technical-documentation.md)
- Detailed architecture diagrams
- Migration playbook
- Operational runbook
- Timeline and dependencies

**For Presentation**:
- Use [Presentation Prompts](../prompt-templates/presentation-prompts.md)
- 20–30 minute deck
- Executive summary + detailed slides
- Key talking points

## Phase 3: Stakeholder Review (1 week)

- Finance review (cost validation)
- Engineering review (technical feasibility)
- Operations review (runbook approval)
- Executive review (decision readiness)
- Incorporate feedback

## Phase 4: Executive Approval (1–2 weeks)

- Present to executive team/board
- Address questions
- Secure funding approval
- Obtain project greenlight

## Phase 5: Implementation Planning (2–4 weeks)

- Detailed project plan
- Resource allocation
- Vendor management
- Risk monitoring plan
- Communication cadence

---

**Total time: 6–10 weeks**

**Key Success Factors:**
- Accurate cost modelling
- Clear technical feasibility
- Realistic timeline
- Board/exec confidence
- Stakeholder alignment
